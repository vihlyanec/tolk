# Выпуск Толк 1.1.10

Mac-версия 1.1.10, сборка 48, опубликована как Latest 20.11.2026 в 10:07 МСК. Тег указывает на `09fe36e406931f42d6a63c7fc0840e74c872dbc3`. [Выпуск на GitHub](https://github.com/vihlyanec/tolk/releases/tag/v1.1.10)

## Проверка Mac и веб-клиента

На точном исходнике прошли 198 тестов Swift, 48 Python, 34 JavaScript и 14 тестов подготовки выпуска. Обе задачи GitHub Actions завершились успешно. [CI](https://github.com/vihlyanec/tolk/actions/runs/44691273319)

Подписанное приложение содержит arm64 и x86_64 с минимальной macOS 14 и SDK 27. Проверены строгая подпись, прежний designated requirement, закреплённый сертификат, открытый ключ Sparkle и четыре звуковых ресурса. Независимая проверка CryptoKit подтвердила Ed25519 для архива, примечаний и ленты.

Публичные файлы и стандартная последняя лента скачаны без авторизации. SHA-256 совпали с подписанными артефактами. Архив имеет 9062530 байт и SHA-256 `34e147b5f8a65508a5a6d71afd88d0e4971d793a09b675a65bd5341e29f931c1`.

В Chrome с временной SQLite проверены копирование с сохранением пробелов, целевой адрес Telegram, фильтр аналитики, история, сворачивание групп, автоматизация завершения и возврат статуса. Проверены настольная и мобильная компоновки. Дерево доступности Chrome подтвердило исходы в доступных именах строк. Независимый повторный просмотр подтвердил эти исправления и подсветку просрочки после возврата задачи в работу.

Нативная проверка интерфейса выполнена по рендерам Demo в двух темах. Живой проход по Mac, физический iPhone и VoiceOver остаются непроверенными.

Публичный сайт отдаёт предыдущую версию. Прямой вход на VPS вернул отказ publickey/password, открытого SSH-сеанса владельца нет. Пакет веба проверен локально. Mac сохраняет совместимость с прежним сервером и передаёт новые поля после согласования поддержки протокола.
