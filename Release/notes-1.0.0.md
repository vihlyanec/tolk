# Толк 1.0.0

Первый публичный выпуск локального менеджера задач для Mac.

- Задачи, проекты, цветные теги и группировка списков.
- Календарь с планированием, перетаскиванием, длительностью и повторениями.
- Быстрое добавление через Control-Q с распознаванием русских дат, времени, тегов и приоритетов.
- Заметки и стикеры через Control-D, оформление текста и кликабельные ссылки.
- Напоминания, звук выполнения, экспорт и резервные копии данных.
- Проверка новых версий и подписанные обновления через GitHub Releases.

Требуется macOS 14 или новее. В архиве приложение для Apple Silicon и Intel. Распакуйте ZIP и перенесите «Толк.app» в «Программы».

Данные хранятся локально. Аккаунт приложения и сервер не требуются. Синхронизации с TickTick в этом выпуске нет.

Приложение пока не подписано Developer ID и не заверено Apple: Gatekeeper может блокировать первый запуск или запуск после обновления. Мы не рекомендуем отключать защиту macOS. Публичная установка и обновление между двумя релизами пока не проверены на отдельном Mac; рекомендуется предварительно экспортировать важные данные.

Если глобальные сочетания заняты другим приложением, используется Control-Shift-Q / D.
