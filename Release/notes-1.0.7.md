# Толк 1.0.7

- Задачи раньше начала рабочего дня теперь видны в календаре: сетка дня и недели автоматически расширяется до самого раннего события.
- При удалении повторяющейся задачи можно выбрать «Удалить только эту задачу» или «Удалить всю цепочку». Второй вариант удаляет выбранный и все следующие повторы, сохраняя предыдущие задачи. Удаление можно отменить через Undo.
