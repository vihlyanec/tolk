# Толк

Локальный менеджер задач и заметок для Mac.

- Списки, проекты и цветные теги.
- Календарь с перетаскиванием и повторяющимися задачами.
- Быстрый ввод Control-Q и заметки Control-D.
- Проверка и установка обновлений из GitHub.

Требуется macOS 14 или новее. Поддерживаются Apple Silicon и Intel.
Этот бесплатный выпуск пока не заверен Apple: при первом запуске macOS может предупредить об отсутствии проверки разработчика или заблокировать запуск.
