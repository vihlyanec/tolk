# Толк 1.0.6

- В канбан добавлена видимая кнопка «Добавить этап». Колонки отображаются и на пустой доске; повторяющиеся названия проверяются при создании.
- Приложение переходит на постоянную подпись для сохранения разрешения Apple Календаря между обновлениями. При первом переходе доступ потребуется разрешить один раз; выбор календарей сохраняется.
- Восстановлена загрузка задач TickTick для аккаунтов, где «Входящие» возвращаются с внутренним идентификатором. Исправлена ошибка «TickTick вернул неполный или неизвестный ответ», останавливавшая синхронизацию.
- Подключение и очередь отправки сохраняются; переподключение аккаунта для этого исправления не требуется. Существующие конфликты задач разрешаются в настройках.
