# Толк 1.1.6

- При паузе фокусировки появляется отдельное окно «С чего продолжить?» по центру экрана. Заметку можно оставить поверх текущего приложения, без перехода в главное окно Толка.
- Сохранённый следующий шаг остаётся виден рядом с таймером на паузе. После продолжения возвращается круглый таймер; заметку можно снова посмотреть при наведении.
- Заметку можно отредактировать у таймера. «Пропустить» и Escape сохраняют прежний текст; при ошибке записи черновик остаётся открытым для повторного сохранения.
