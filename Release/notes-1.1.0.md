# Толк 1.1.0

Общий аккаунт Mac и веб-версии: задачи, заметки, проекты, метки, чек-листы, даты и настройки синхронизируются через ваш сервер. Подключение находится в Настройках → Аккаунт и подтверждается в браузере. Существующие данные объединяются, конфликтующие правки требуют выбора версии.

Помодоро продолжает общий сеанс на другом устройстве, включая паузу и заметку «С чего продолжить». Веб-интерфейс получил цвета, кнопки и отметки задач из нативного приложения, адаптированные для iPhone.

TickTick и Apple Календарь обслуживаются Mac; ключи провайдеров остаются на нём. Для Web Push на iPhone установите веб-приложение на экран «Домой» и разрешите уведомления. Первое подключение аккаунта и доставка на конкретном iPhone требуют пользовательской проверки.
