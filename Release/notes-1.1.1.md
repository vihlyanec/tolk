# Толк 1.1.1

Три отдельных звука: начало фокуса, завершение фокуса и напоминание о задаче. Чистый звонкий тон с мягкой низкой основой; у каждого сигнала своя мелодия и тональность.

При продолжении фокуса после паузы звучит сигнал начала. Ожидающие напоминания о задачах автоматически получают новый звук. Звук отметки выполненной задачи сохранён.
