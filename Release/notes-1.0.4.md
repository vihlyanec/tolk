# Толк 1.0.4

- Этапы канбана TickTick, их порядок и расположение задач теперь загружаются автоматически вместе с синхронизацией.
- Переименование этапов сохраняет задачи; одноимённые этапы различаются. Местный перенос задачи в Толке имеет приоритет и остаётся локальным. Если этап TickTick недоступен, прежнее размещение сохраняется, а в настройках появляется пояснение.
- Убран лишний логотип справа в напоминаниях: он больше не добавляется как картинка-вложение.
- Уточнена упаковка и регистрация системной иконки приложения. Для баннера и значка приложения используется один файл ICNS.
- Запланированные напоминания старого формата автоматически пересоздаются без вложения; время, звук и привязка к задаче сохраняются.

Изменение относится к новым уведомлениям. Уже доставленные баннеры в истории macOS не перерисовываются.
