# Толк 1.0.9

- Помодоро вынесен в отдельный раздел: крупный круглый таймер, выбор задачи и обзор текущего сеанса. Запуск фокуса из задачи сохранён.
- При паузе открывается окно «С чего продолжить?». Заметка необязательна: её можно сохранить или пропустить. Следующий шаг отображается рядом с таймером и сохраняется после перезапуска.
- Предыдущие сохранённые сеансы Помодоро совместимы с обновлением.
