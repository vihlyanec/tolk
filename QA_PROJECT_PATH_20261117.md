## Поведение

`Тренировка /Личное/Спорт !1` выбирает проект Личное, существующий этап Спорт и высокий приоритет. Каталог позволяет распознать имена с пробелами; подсказки вставляют `/Личное пространство/Спорт силовой`. Старые кавычки вокруг обеих или одной части совместимы. Для буквального слеша, кавычки или обратного слеша внутри имени каноническая команда использует экранированные кавычки; хранимые имена не меняются. Неизвестный этап по явному ответу пользователя выбирает только проект, «Без раздела», с пояснением. Новый этап не создаётся. Неизвестная некавыченная часть пути кончается на пробеле; остальные слова остаются названием. Неизвестный проект остаётся текстом. URL и буквальные команды сохраняются.

Полная форма откладывает перенос всего пути до blur/save: это необходимо для дописывания многочастных имён и этапов с пробелами. Приоритеты/теги продолжают переноситься при пробеле. Глобальная/inline полоски сохраняют прежнюю схему Return: применить подсказку, затем добавить. В веб-форме путь распознаётся в preview; title очищается при создании, выбранный вручную другой проект сбрасывает этап. Старые дефолты вне полной формы сохранены.
