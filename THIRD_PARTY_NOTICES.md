# Сторонние компоненты

Толк использует [Sparkle 2.10.1](https://github.com/sparkle-project/Sparkle/releases/tag/2.10.1) для обновлений macOS-приложения. Лицензия Sparkle включена в каждую сборку: `Толк.app/Contents/Resources/Sparkle-LICENSE.txt`. Официальный бинарный архив подключён через Swift Package Manager с закреплённой SHA-256.

Уведомления о правах и лицензии компонентов Sparkle сохранены внутри оригинального framework. Его вложенные инструменты распространяются с оригинальными подписями. Это не делает само приложение «Толк» подписанным Developer ID или заверенным Apple.

Операционная система предоставляет SwiftUI, AppKit, WebKit, CryptoKit, UserNotifications и SQLite.
