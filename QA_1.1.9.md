# Выпуск Толк 1.1.9

Mac-версия 1.1.9, сборка 47, опубликована как Latest 18.11.2026 в 22:54 МСК. Тег указывает на `d67f18a621003c4666a2f63f348621e122a008a5`. [Выпуск на GitHub](https://github.com/vihlyanec/tolk/releases/tag/v1.1.9)

## Проверка Mac

На точном исходнике прошли 194 теста Swift, 32 JavaScript, 45 Python и 14 тестов подготовки выпуска. Обе задачи GitHub Actions успешно завершились. [Запуск CI](https://github.com/vihlyanec/tolk/actions/runs/44382379777)

Проверены сборки arm64 и x86_64, обе с минимальной macOS 14 и SDK 27. Строгая проверка подписи приложения, закреплённого сертификата и соответствия designated requirement версии 1.1.8 прошла. Независимая проверка CryptoKit подтвердила Ed25519 для архива, примечаний к выпуску и самой ленты. Сохранены адрес ленты, публичный ключ и четыре звуковых ресурса.

Шесть снимков, полученных из подписанного приложения, побайтово совпали с Demo. Для сценария смены отдельно проверены светлая и тёмная темы, узкая неделя, совпадающее начало и минутное событие. Семь проверок мышью в нативном окне охватили открытие смены и задачи, выбор времени вставки и создание задачи в свободной части смены. Проверка проводилась на вымышленных данных. На физическом iPhone и с VoiceOver этот выпуск не проверялся.

Все четыре файла скачаны с публичных URL без авторизации. Контрольные суммы совпали с локально проверенным выпуском. Стандартный адрес ленты Sparkle вернул байты опубликованной версии. Архив `Tolk-1.1.9.zip` — 8801549 байт, SHA-256 `e831150839843a01b93822198d3d01c28427661750a2f33729a2ab483202cc03`.
