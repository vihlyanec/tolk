# Толк · 1.0.0

Личный нативный менеджер задач для Mac. SwiftUI + AppKit, локальная SQLite-база, без подключения TickTick и без импорта личных записей.

## Установка

[Скачать последний выпуск для Mac](https://github.com/vihlyanec/tolk/releases/latest). Распакуйте ZIP и перенесите «Толк.app» в «Программы». Поддерживаются macOS 14+, Apple Silicon и Intel; Swift и инструменты разработчика для готового приложения не нужны.

Проверка новых версий: меню «Толк → Проверить обновления…». Автоматическую проверку можно включить в настройках. Данные хранятся отдельно от приложения. Пока нет Developer ID и заверения Apple, macOS может предупреждать или блокировать запуск; системную защиту отключать не нужно.

Первый опубликованный выпуск: [1.0.0](https://github.com/vihlyanec/tolk/releases/tag/v1.0.0).

## Сборка

Нужны macOS 14+ и Swift 6.2+ (Command Line Tools). При первой сборке Swift Package Manager скачивает официальный Sparkle 2.10.1 и проверяет его SHA-256. Версия и контрольная сумма зафиксированы в Package.swift.

```sh
zsh scripts/build.sh
```

Открыть `build/Толк.app` через Finder. В этой локальной сборке используется ad-hoc подпись; распространение на другие Mac и notarization пока не настроены. Устанавливать платный аккаунт разработчика для локальной сборки не требуется.

## Изменения 0.9.0

Выполненные задачи остаются в календаре с галочкой, зачёркнутым названием и приглушённой заливкой. Будущие повторы рассчитываются при просмотре недели/месяца, без создания лишних записей; редактирование или выполнение конкретного повтора сохраняет отдельное исключение. Старые цепочки повторов поддерживаются. В карточке «Весь день» длительность скрыта, последнее значение сохраняется на случай возврата ко времени.

Очередь уведомлений обновляется последовательно и только при изменениях. Повторные одинаковые правила объединяются; добавлены логотип и звук Completion.wav. Звук и показ баннеров также зависят от разрешений macOS. Demo не планирует системные уведомления.

Заметки и стикеры редактируются в одном режиме: заголовки, выделение, списки, чекбоксы, цитаты, таблицы, код и ссылки. Разметка хранится в прежнем поле Markdown, старые заметки открываются без миграции. Вставка из буфера — текст; HTML и скрипты пользователя не выполняются.

Пока репозиторий и постоянный ключ не настроены, публикация заблокирована. Сохранён идентификатор local.takt.mac и прежняя папка данных Takt.

## Основные действия

- Строка над списком добавляет задачи с тем же умным вводом; доступна во «Всех», «Входящих», «Сегодня», «Следующих 7 днях», проектах и тегах.
- Control-Q — быстро добавить задачу. `/` выбирает проект, `#` тег, `!` приоритет. Названия проектов с пробелами выбираются из подсказок или записываются как `/"Рабочие задачи"`.
- Control-D — новая заметка-стикер. Закрытие стикера сохраняет заметку. Настройки позволяют включить временные Control-Shift-Q/D; при занятом сочетании этот вариант используется автоматически. Настройки TickTick не меняются.
- Плюс у «Проекты» и «Теги» создаёт собственную структуру. Правый клик позволяет изменить проект/тег и добавить раздел. Канбан включается в выбранном проекте; основной вид — список.
- Задачи без времени видны справа в календаре. Длительность задаётся до назначения даты. Перенос в сетку назначает время, перенос обратно снимает время, сохраняя длительность и дату. Двойной клик по пустой сетке создаёт задачу на выбранное время; протягивание по пустому месту задаёт интервал. Масштаб меняется кнопками лупы; по умолчанию час занимает 96 пунктов. На узком окне все семь дней автоматически помещаются в доступную ширину.
- У календарного блока есть чекбокс. Края блока меняют начало/окончание; две пересекающиеся задачи располагаются рядом внутри дня. Подложка полупрозрачная.
- В списке выбор задачи открывает детали справа, даже если панель была скрыта; граница списка и деталей меняет ширину перетаскиванием. В календаре детали открываются во всплывающем окне, очередь распределения остаётся справа. Боковая панель проектов в календаре скрыта. В заметках и стикерах единый редактор с непосредственным форматированием, кликабельными ссылками и сохранением в Markdown. В описаниях задач остаётся редактор Markdown с отдельным просмотром.
- Cmd-Z отменяет изменение записи, Cmd-Shift-Z повторяет. Удаление переносит запись в Корзину, откуда доступно восстановление.
- Напоминания требуют разрешения macOS; поддерживаются задачи со временем и на весь день, по нескольку уведомлений. Приложение остаётся запущенным после закрытия главного окна. Полное завершение прекращает работу глобальных клавиш. Простые повторы создают следующий экземпляр после завершения текущего.

## Умный ввод

Пример: `Подготовить отчёт завтра в 14:00 на 45 минут !1 #работа /Работа`.

Прямо во вводе принятые парсером фрагменты выделяются цветом: дата зелёным, время синим, длительность бирюзовым, проект и тег своим цветом, приоритет красным/оранжевым/синим. Неизвестные и некорректные свойства не подсвечиваются как распознанные. Слова «важно» и «срочно» задают высокий приоритет; также распознаются «высокий/средний/низкий приоритет». Явное !0…!3 имеет преимущество.

Поддерживаются сегодня/завтра/послезавтра, дни недели, ДД.ММ и ДД.ММ.ГГГГ, ЧЧ:ММ, «через N минут/часов/дней», «на N минут/часов». !1 высокий, !2 средний, !3 низкий, !0 без приоритета. Дата без времени не получает скрытого времени. Перед добавлением видны распознанные свойства. Длительность можно выбрать отдельным меню в быстром окне и в строке списка. Неизвестные проект/тег остаются в названии; явная подсказка позволяет создать их. URL не разбираются как проекты.

## Данные и восстановление

База: `~/Library/Application Support/Takt/takt.sqlite`, рядом `Backups/`. Перед первым изменением дня создаётся согласованная SQLite-копия. Настройки → Экспорт сохраняет все данные в JSON; восстановление проверяет формат и связи и создаёт отдельный экспорт текущих данных перед заменой. При повреждении базы приложение показывает ошибку и блокирует запись, а не подменяет данные пустой базой.
