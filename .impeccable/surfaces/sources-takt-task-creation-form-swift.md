# Полная форма новой задачи

Mode: Operate. Узкое расширение нативного Толка. Верхняя кнопка «Задача» открывает полную форму, название понимает существующие команды и переносит их в поля, убирая синтаксис из названия. Подтверждение пользователя: всегда пустые поля, не наследовать дату/проект/теги текущего раздела. Задача появляется только после «Добавить»; отмена не создаёт запись.

## Direction contract

THESIS: Заполнить всю задачу за один проход с умным названием и доступными ручными полями.
OWN-WORLD: Установленные SF, SF Symbols, adaptive NSColor, синий акцент и нативные controls инспектора; никакого нового визуального мира.
STORY: Верхняя «Задача» → пустая полная форма → название/команды или ручные поля → добавить один раз либо отменить.
FIRST VIEWPORT: Закреплённый заголовок, умное название и основные свойства; при высоте680pt видны описание и заголовок чек-листа. Полный чек-лист и напоминания доступны прокруткой. При высоте460pt прокручиваются также свойства. Отмена/Добавить всегда закреплены.
FORM: Нативный sheet шириной600pt в основном окне, плотность существующего инспектора. Узкая точно заданная доработка, concept tournament не применим; seed: none (unavailable).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Новых анимаций нет: часто используемый ввод и перенос команды мгновенны. Глобальная быстрая полоска и строка внутри списка сохраняют существующее поведение. На этапе локального review новый релиз ещё не был разрешён.

## Реализованное поведение

Каждое открытие верхней кнопкой «Задача» создаёт отдельный пустой TaskCreationDraft: название/описание/чек-лист/теги пусты, Входящие, Без даты, Без приоритета, Не повторять; стандартная длительность Item —30мин. Ни Входящие/Сегодня/Неделя, ни текущий проект/тег, ни быстрый черновик не задают значения этой формы. Отмена только закрывает sheet. Другие пути быстрого добавления сохраняют свой прежний контекст.

SmartCaptureInput переносит принятые команды приоритета, проекта, тега и длительности после пробела либо при выходе из названия/сохранении. Например, «План !1 » становится «План » с полем «Высокий». Даты и время остаются подсвеченными в названии до выхода/сохранения, чтобы фраза «12 дек 2027 в 10» разбиралась целиком. Неизвестные, невалидные и явно оставленные буквальными команды сохраняются текстом. Остальные ручные поля не перезаписываются. Конкурирующие признанные команды приоритета/проекта удаляются за один проход с выбранным парсером значением; повторный выход или сохранение его не меняет. Новая команда, введённая позже, может изменить поле. Этот режим QuickParser включён только формой.

Полные поля: проект и условный раздел, дата/время через TaskDatePopover, длительность, приоритет, повтор и интервал дней, теги, Markdown-описание, чек-лист и timed/all-day напоминания. Напоминания требуют выбранной даты. Середина прокручивается под фиксированными заголовком и footer. Ширина600pt, обычная высота680pt ограничена видимой областью экрана. Используются прежние SF/SF Symbols, Palette.sidebar/canvas, InspectorDropdown/Pill, MetadataFlow и семантические цвета; внутренние отступы22pt, основной текст13pt, подсказки11pt, заголовок20pt semibold.

Tab/Shift-Tab в названии формы вызывают нативный следующий/предыдущий key view без вставки табуляции; флаг tabMovesFocus по умолчанию выключен для других SmartCaptureInput. Потеря фокуса завершает распознавание. Shift-Return переводит к описанию; Return в названии и⌘Return сохраняют, Escape/Отмена закрывают. Очистка команд сохраняет UTF-16 caret/selection, включая emoji. Эти связи проверены source и тестами; реальное ручное прохождение sheet с клавиатуры не наблюдалось.

Только «Добавить» записывает готовый Item, без defaults текущего списка. Повторный UUID отвергается; задача и созданные из описания теги образуют одну Undo-транзакцию. Недоступный проект/тег или ошибка хранилища оставляют локальный черновик и показывают текст ошибки у действий. Удалённый тег можно убрать и повторить сохранение. Пустое название блокирует добавление.

Установленный Толк, личные записи и сервер не менялись. Глобальные PRODUCT.md/DESIGN.md/`.impeccable/design.json` сохранены: это расширение существующей системы, а не её замена.
