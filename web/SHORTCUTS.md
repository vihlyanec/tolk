# Добавить задачу с iPhone

Локальная реализация от 11 ноября 2026. Для работы с личным аккаунтом сначала требуется установка серверных изменений; файл команды сам по себе сервер не обновляет.

1. В веб-Толке откройте Настройки → Быстрая команда iPhone → Скачать команду.
2. Откройте файл «Добавить в Толк.shortcut» на iPhone и добавьте команду.
3. В настройках Толка нажмите «Создать ключ». Скопируйте показанный ключ в первый блок «Текст» команды вместо заглушки. Ключ показывается один раз. Пароль аккаунта в команду не вводится.
4. Запустите команду. Заполните название, выберите приоритет, дату (либо «Без даты»), проект (либо «Входящие») и тег (либо «Без тега»).
5. Дождитесь сообщения «Задача добавлена в Толк». На Mac она появится после очередной синхронизации; Mac не обязан быть включён в момент добавления.

Форма — последовательные нативные поля и списки приложения «Команды», без открытия веб-приложения. Дата без времени создаёт задачу на весь день. Один тег на задачу. Для запуска команду можно добавить на экран «Домой» через её меню в приложении «Команды».

Команда делает два небольших запроса: справочники проектов/тегов и создание задачи. Список задач, тексты заметок и интеграционные ключи ей недоступны. При отсутствии интернета форма не отправляется; офлайн-очереди у команды нет. Не запускайте её заново вслепую после неопределённого сетевого сбоя: сначала проверьте, появилась ли задача. Повтор HTTP-запроса с прежним requestID не создаёт дубль; новый запуск команды получает новый requestID.

Ключи можно отозвать в том же разделе веб-настроек. На сервере хранится только хэш. Отзыв прекращает доступ команды; новый ключ нужно вставить в первый блок «Текст». Не публикуйте копию команды, в которую уже вставлен ваш ключ.

## API

Все запросы POST JSON, HTTPS. `/api/capture/token`, `/api/capture/tokens`, `/api/capture/revoke` требуют существующую браузерную cookie-сессию и точный Origin. Ключ добавления не подходит для этих путей и для device/sync.

`/api/capture/options` с `Authorization: Bearer <ключ>` возвращает новый requestID, словари `projects`/`tags` (название с коротким ID → полный UUID), списки `projectNames`/`tagNames`. Пустые значения обозначают Входящие/Без тега. Доступны только активные проекты задач и неудалённые теги этого аккаунта.

`/api/capture` с тем же заголовком принимает:

```json
{"requestID":"UUID из options","title":"Купить лампу","priority":0,"date":"2026-12-12","projectID":"","tagID":""}
```

Также поддерживаются body, time HH:mm и duration 1…10080 минут. Приоритет — 0/1/2/3 либо Без приоритета/Высокий/Средний/Низкий. Дата YYYY-MM-DD, пустая дата — без даты; для времени обязательна дата. Используется часовой пояс аккаунта, DST gap отвергается. Клиент не задаёт accountID, deleted, completed, recurrence или существующий id задачи.

Создание записи, журнал изменений и квитанция requestID фиксируются одной SQLite-транзакцией. Идентичный повтор возвращает ту же квитанцию, другое содержимое с прежним ID отклоняется. Проекты/теги проверяются на принадлежность аккаунту и доступность в момент сохранения. Лимит 60 запросов capture/options вместе в минуту на IP; до 20 ключей на аккаунт.

Шаблон без секретов генерируется `python3 scripts/build_capture_shortcut.py --output /private/tmp/tolk-unsigned.shortcut`, затем подписывается штатным `shortcuts sign --mode anyone --input /private/tmp/tolk-unsigned.shortcut --output web/public/tolk-add-task.shortcut`. При подписи Apple получает только шаблон без ключа пользователя.

Нативное выполнение на физическом iPhone пока не проверено. Предпросмотр macOS подтвердил нативные действия формы и POST JSON; найденное неизвестное действие UUID заменено чтением requestID из ответа options. Финальное исполнение исправленного шаблона требует отдельной проверки на устройстве.
