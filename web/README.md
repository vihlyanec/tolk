# Толк · веб-клиент

Веб-клиент общего аккаунта для Mac и iPhone. Оформление наследует установленный нативный Толк: синий акцент, нейтральные поверхности, круглые отметки задач и компактные свойства. Физическое подключение личного Mac и проверка push на iPhone выполняются после установки новой нативной версии и пользовательского подтверждения аккаунта.

## Возможности

- Общие задачи, заметки, проекты, вложенные метки, чек-листы, даты, длительность, повторы, напоминания, настройки и текущий Помодоро с заметкой паузы.
- HTTPS-аккаунт, долговечная офлайн-очередь IndexedDB, идемпотентные операции, объединение независимых полей и явный выбор конфликтов.
- Подключение Mac через одноразовое подтверждение в браузере. Bearer в Keychain привязан к origin и аккаунту; пароль аккаунта не сохраняется в Mac.
- Недельный календарь с очередью на широком экране; повестка выбранного дня на телефоне. Возврат во Входящие очищает проект и дату.
- TickTick и Apple Календарь обслуживаются подключённым Mac. Секреты провайдеров не передаются на сервер. Настройки источников сохраняются в аккаунте; события Apple отображаются только для чтения. При выключенном Mac новые внешние изменения не поступают.
- Серверный Web Push для напоминаний и конца фазы. На iPhone требуется экран «Домой» и разрешение; реальная доставка ещё не подтверждена.

## Разработка и проверки

Python3.11+ с SQLite/scrypt, Node22+ для клиентских тестов:

```sh
python3 web/server/main.py --setup --db /private/tmp/tolk-test.sqlite --port 8788
python3 -m unittest discover -s web/tests -v
node --test web/tests/*.test.js
```

main.py — только локальный HTTP адаптер для CRUD. Production WSGI поддерживает pairing и push; эти маршруты проверяются WSGI-тестами. Контейнер ставит gunicorn и pywebpush. Production слушает только loopback за HTTPS reverse proxy; не открывать dev-сервер в сеть.

## Подключение

После установки версии Mac с общим аккаунтом: Настройки → Аккаунт → «Подключить и объединить данные». В открывшемся сайте войти в существующий аккаунт и явно подтвердить свой Mac. Записи двух устройств объединяются, совпадающие UUID не дублируются. Различающиеся правки одного поля требуют выбора. Сделайте штатную резервную копию перед первым объединением.

Публичной регистрации нет: первый аккаунт создаётся единожды с кодом активации. Восстановление пароля и внешние резервные копии пока не реализованы. Неотправленная офлайн-очередь хранится только на устройстве, браузер может удалить своё хранилище. iOS отправляет изменения при возвращении в приложение; установка PWA не даёт постоянного фонового исполнения.
